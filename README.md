# Scriptl OS

Scriptl OS is an operating system developed by Nechi Studio.

This project aims to build a custom operating system from scratch using C and Assembly.

---

## Current Version

v0.1 (Genesis)

Status: Development

---

## Project Goals

- Build custom bootloader
- Build custom kernel
- Build CLI system
- Build file system
- Build drivers
- Build GUI

---

## Project Structure

boot/       - bootloader  
kernel/     - kernel core  
drivers/    - hardware drivers  
include/    - headers  

---

## How to run Scriptl OS

### Requirements

- nasm
- qemu
- make

### Build

Make run:
```
make run
```

Make clean:
```
make clean
```
